# Менеджер пакетов

Расширение 1С: загружает в базу расширения, обработки и отчёты
(`.cfe`, `.epf`, `.erf`) из GitLab и GitHub.

Нужна платформа **8.3.23** и выше.

## Как начать

Пакет — это опубликованное расширение, обработка или отчёт
(`.cfe`, `.epf`, `.erf`) со своим именем и версиями.
Сначала его публикуют из репозитория, потом ставят в 1С.

Пайплайн публикует файлы в GitLab Generic Package Registry
или в GitHub Releases.

В корне репозитория заводите `pm-packages.json`: список пакетов,
которые нужно собрать. В CI добавляете шаг публикации. Готовый
шаг для GitLab, GitHub Actions и Jenkins отдаёт обработка
«Генератор шаблонов публикации».

Когда пакеты уже в реестре или в релизе, в справочнике
«Источники пакетов» указываете сервер и путь проекта.
Закрытый репозиторий — токен на чтение в той же карточке.
Публичный — токен не нужен.

В менеджере выбираете пакет, версию и ставите.
