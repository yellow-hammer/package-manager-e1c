# Журнал изменений

Все заметные изменения в этом проекте будут задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [0.1.1] - 2026-08-31


### Исправления

- Сняли фильтр типа релиза при установке выбранной версии

- Связали пакет с расширением базы по имени внутри cfe


## [0.1.0] - 2026-08-28


### Новые возможности

- Добавили расширение менеджера пакетов и каркас проекта

- Добавили источники пакетов, проверку обновлений и генератор шаблонов CI

- Научили читать пакеты из реестра GitLab и релизов GitHub

- Сделали поле подсказки генератора многострочным

- Ограничили публикацию GitLab тегами ветки релиза

- Нарисовали иконку раздела и убрали неиспользуемые картинки


### Исправления

- Поправили провайдера GitHub и шаблон публикации GitLab

- Выровняли имена тестовых модулей и состав расширения тестов

- Уточнили ошибки провайдеров при превышении лимита запросов

- Исправили обновление расширений и сверку установленных пакетов

- Остановили установку только на критичных проблемах применимости

- Перенесли публикацию GitLab в tools/ci и включили UTF-8

- Сравнили важность проблем применимости точным совпадением


### Рефакторинг

- Убрали лишние параметры в вызовах оповещений

- Убрали дублирующую кнопку обновления и сузили колонки версий


### Документация

- Переписали README, справку источников и правила репозитория

- Переработали документацию и добавили скриншот менеджера

- Добавили аватар проекта из иконки раздела


### Тестирование

- Закрыли тестами сборку исходников в шаблоне GitLab

- Вынесли тесты в отдельное расширение и зафиксировали YAxUnit 25.12


### Обслуживание

- Настроили конфигурацию-заглушку для тестов

- Добавили настройки Vanessa для первой инициализации

- Настроили сборку, тесты и публикацию релиза в GitHub Actions

- Добавили тестовые расширения в настройки редактора

- Перевели проверки на матрицу платформ 8.3 и 8.5 с releases.1c.ru

- Перевели тесты на автономный сервер и проверку метаданных на ibcmd

- Подключили git-cliff и журнал изменений к релизу
