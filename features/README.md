# Сценарные тесты (Vanessa Automation)

Сценарии на Gherkin, проверяющие расширение через интерфейс.

| Каталог | Что проверяет |
| ------- | ------------- |
| `Смоук/` | Объекты расширения открываются без ошибок |
| `Источники/` | Заведение источника, умолчания, контроль заполнения |
| `Генератор/` | Формирование шаблона публикации и подсказки |

Запуск и подготовка окружения описаны в [tests/README.md](../tests/README.md).

## Теги

| Тег | Смысл |
| --- | ----- |
| `@tree` | Показывать в дереве сценариев Vanessa |
| `@smoke` | Дымовой набор: минимальная проверка работоспособности |
| `@Источники`, `@Генератор` | Группировка по функциональности |
| `@IgnoreOnCI` | Не запускать на сборочной машине |

`@IgnoreOnCI` перечислен в `СписокТеговИсключение` файла `tools/VAParams.json`.
Сейчас им ничего не помечено — тег заведён заранее для сценариев, которым
понадобится живой источник в сети.

## Шаги пишутся только из словаря Vanessa

Шаг, которого нет в словаре, падает с «Не найдена процедура или функция для
выполнения шага» — сценарий при этом считается упавшим, а не пропущенным.
Придумывать формулировки нельзя, их надо смотреть.

Словарь лежит внутри `vanessa-automation-single.epf`. Достать его так:

```bash
vrunner decompileepf oscript_modules/vanessa-automation-single/vanessa-automation-single.epf build/out/va-src --settings env.json
```

Дальше искать по строкам регистрации шагов — `ДобавитьШагВМассивТестов`.
Полезное из уже найденного:

| Задача | Шаг |
| ------ | --- |
| Значение поля | `Тогда значение поля с именем 'ИмяПоля' содержит текст "..."` |
| Ввод текста | `И в поле с именем 'ИмяПоля' я ввожу текст "..."` |
| Очистка поля | `И я нажимаю кнопку очистить у поля с именем 'ИмяПоля'` |
| Выбор из списка | `И из выпадающего списка с именем 'ИмяПоля' я выбираю точное значение "..."` |
| Сообщение пользователю | `Затем я жду, что в сообщениях пользователю будет подстрока "..." в течение 30 секунд` |
| Строки списка | `И таблица формы с именем 'Список' содержит строки:` |
| Диалог, если он появился | `Затем Если появилось окно диалога я нажимаю на кнопку "Нет"` |

Последний нужен после закрытия изменённой формы: заголовок окна в этот
момент получает звёздочку, и проверять его по точному совпадению нельзя.
