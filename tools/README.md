# Инструменты

Настройки запуска проверок. Все команды запускаются из корня репозитория
и читают `env.json`.

| Файл | Назначение |
| ---- | ---------- |
| `yaxunit.json` | Параметры прогона модульных тестов YAxUnit |
| `xUnitParams.json` | Дымовое открытие форм (`vrunner xunit`) |
| `VAParams.json` | Сценарии Vanessa Automation |
| `VAParams.init.json`, `vrunner.init.json` | Первичное заведение локальных тестовых источников (`@Init`) |
| `syntax-check-excludes.txt` | Исключения синтакс-контроля: заимствованные модули и тестовое расширение |
